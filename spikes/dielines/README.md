# 型の線のファイル（DXF の読み込みの試し用）

DXF などの型の線のファイルを読んで、パケノバの型にする試作（S07）に使う見本。

## pacxio/

- 作ったもの: [pacxio](https://pypi.org/project/pacxio/) 0.0.5（MIT ライセンス、オープンソースの型の生成器）の `structure_files` で、2026-11-25 に生成した。
- 形式: 1 つの型につき DXF（R12、単位は mm、レイヤー `CUT` `CREASE`、一部に `GLUE`）、CF2、SVG、PDF。
- 寸法は内寸。紙は ECMA（A で始まる番号）が板紙 SBS 350、FEFCO（数字だけの番号）が B フルートの段ボール（pacxio の初期値）。
- `_overview.png` は全部を並べた絵。

| 番号 | 規格 | 箱 | 寸法 L×W×H (mm) |
|---|---|---|---|
| A20.20.03.01 | ECMA | 差し込み箱（上下とも差し込み＋防塵フラップ） | 100×60×150 |
| A20.20.01.03 | ECMA | 差し込み箱（差し込みのつく向きが違うもの） | 100×60×150 |
| A10.20.03.01 | ECMA | 上は差し込み、底は 4 枚のフラップを重ねる | 100×60×150 |
| 0215 | FEFCO | 上は差し込み、底は組み底（1・2・3 で組む底） | 120×80×100 |

| 0427 | FEFCO | 通販でよく使う、フタつきの組み箱（N 式） | 280×210×60 |
| 0201 | FEFCO | みかん箱（A 式段ボール） | 300×200×150 |
| 0217 | FEFCO | 持ち手つきの山形のフタ（ゲーブル型に近い） | 200×120×150 |
| 0300 | FEFCO | 天地箱（`base` が身、`lid` がフタの 2 枚） | 200×150×60 |

## まだないもの

- ほかの道具で作られた DXF。生成器によってレイヤーの名前が違う（`FOLD`、`PERFORATION`、`BLEED` など）ので、読み込みで当てる名前の試しになる。
- ピロー型（曲線の折り線）の DXF。
