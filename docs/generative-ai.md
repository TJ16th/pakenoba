# 新パケノバ 生成AIの検討

- 作成日: 2026-11-24
- 状態: 1（面ごとの選択範囲と、組み立て向きの PSD）を作った。2 以降は案
- 関連: [紙・コート・加工の検討](finishes.md)、[画面設計の検討](ui-design.md) 4.5、旧パケノバ ADR-0003（ComfyUI の信頼境界）、INST-0173（AI 生成ベータ）、INST-0183〜0185（面投影、陰影と折り目の除去）

## 1. 本人の要望（2026-11-24）

- 生成AIの機能を入れたい。少なくとも、パッケージの輪郭を ControlNet に渡して、それに合わせて画像を生成し、柄として取り込みたい。
- ターンテーブル系の AI モデル（MiniMax H3 など）で箱を回し、反対側の面も作りたい。
- ローカルの ComfyUI を使う前提でよい。
- PSD で書き出して、Photoshop の生成塗りつぶし（Firefly）で面を描く流れも使いたい。ブラウザ版の Firefly でもよい。

## 2. 旧パケノバでのやり方

- 3D 表示の斜めから見た箱の輪郭を ComfyUI の ControlNet へ渡し、生成した箱の絵を、見えている面ごとに四隅で台形補正して面へ貼った。見えていない反対側の面は、向かいの面の絵を使い回した。
- そのあと、陰影と折り目を取る処理を試した（INST-0184、0185）。
- ComfyUI はローカルか、組織の管理する場所だけにつなぐ。生成した PNG に埋め込まれた情報（プロンプト、ワークフロー）は、信頼できない入力として扱い、残すか消すかを選べる（ADR-0003）。

## 3. 考え方

- 形はパケノバが決め、AI には絵だけを描かせる。パケノバは、箱の形と、面ごとの向き、描いたときのカメラを正確に知っている。
- 展開図では、フタや底の面が逆さや横向きに並ぶ。展開図のまま描かせると、組み立てたときに絵や文字が逆さになる。描かせるのは「組み立てたときの向き」に並べた絵にし、パケノバが展開図へ戻す。
- 「描かせるための画像を書き出す」と「描いた絵を面へ戻す」は、ComfyUI 専用にしない。Photoshop、ブラウザ版の Firefly（構図の参照は輪郭と奥行きを見る）、ほかのサービスでも同じ流れで使えるようにする。

## 4. 作る順

1. 面ごとの選択範囲と、組み立て向きの PSD（作った。5 章）
2. 斜めから見た制御画像（輪郭、奥行き、面の向き、マスク）の書き出しと、その向きの絵を面へ貼り戻す機能。カメラが分かっているので、四隅の台形補正ではなく、画素ごとに正確に戻す（曲面も）。陰影は、いまある「陰影をならす」を使う。面の端の線の除去は、旧パケノバから移す
3. ComfyUI に直接つなぐ（API 形式で保存したワークフローの、目印を付けたノードに、制御画像とプロンプトを入れる。候補を並べ、箱の上で見比べ、残すものだけを柄にする）
4. 反対側の面: パケノバが箱を何方向かから描き、方向ごとに生成させて面へ戻す。MiniMax H3（Hailuo 3.0。2026-07-31 公開、土台の重みも公開）の 360 度の一周の LoRA は実験として試す（動画のコマごとの向きは、パケノバが描いた輪郭と照らし合わせて決める）

## 5. 面ごとの選択範囲と、組み立て向きの PSD（2026-11-24）

- **面ごとの選択範囲**: 型紙の PSD（表と裏）に、面ごとのアルファチャンネルを入れる。名前は面の名前（「正面」「右側面」など）、白がその面と、その面の塗り足し。Photoshop の新しいアルファチャンネルと同じく、赤の 50% で「マスク範囲に色を付ける」。Photoshop でチャンネルを Ctrl + クリックすると、その面だけを選べる。のりしろと、閉じると隠れる面は入れない。加工の版（スポットカラーチャンネル）のあとに並ぶ（`art::add_channels`）。
- **組み立て向きの並び**（`Surface::unfold`、`app/atlas.rs`）: 正面を、まっすぐ立って見える向き（`Surface::up`）でまん中に置き、折り線と合わせ目をたどって、外側の面を 1 枚の平面へ開く。折り線を合わせ目より先にたどり、どの面も 1 回だけ置く。ほかの面と重なる面は置かない。差し込み箱では、正面の右に右側面、左に左側面、その先に背面、上に天面、下に底面の十字になる。
- **組み立て向きの PSD**（出力の「型紙（PSD）」の「組み立て向きの PSD を保存…」）: 解像度と塗り足しの幅は、型紙の PSD と同じ設定。レイヤーは下から、確認用の紙の色（ガイド）、絵柄（読み込んだ展開図の絵を並べ直したもの。なければ透明）、立体の上で置いた柄をまとめたもの、ガイド（面の輪郭。名前に `(PAKENOBA assembled view)` の目印）。面ごとの選択範囲も入る。保存は別のスレッドで動かす。
- **読み戻し**: 目印のある PSD をウィンドウへドロップ（か「展開図の絵を読み込む」）すると、ガイドと柄のレイヤーを除いた絵を、面ごとに展開図の場所へ戻し、紙の表の「展開図の絵」にする（元に戻せる）。名前は「元の名前（組み立て向きから）.psd」。PSD の解像度と画素の数から、まわりの余白（塗り足しの幅）を求める。いまの箱と大きさが合わなければ（型や寸法を変えた）、そう知らせて読まない。塗り足しは、並びの上でその面の外側に描かれた絵を使うので、天面へ回り込む絵は、正面の上の塗り足しにそのまま続く。
- 並べて戻すと、面の中ほどは同じ色に戻ることを試験で確かめた。どの型（差し込み箱、ゲーブル型、角柱、ピロー型）でも、面が重ならずに並ぶことも確かめた。

### 型紙の PSD の「絵柄」を、刷るものだけにした（2026-11-24）

- それまでは、型紙の PSD の「絵柄」のレイヤーに、確認用の紙の色（薄いベージュ）を塗っていた。Photoshop で描いて読み戻すと、紙の色まで「刷る絵」として入り、入稿用 PDF でベージュが刷られてしまう。
- 「絵柄」は刷るものだけ（何もなければ透明）にし、確認用の紙の色は、いちばん下のガイドのレイヤー「ガイド（紙の色。確認用）」に分けた。読み戻すときは、ほかのガイドと同じく除く。
- 読み込んだ展開図の絵は「刷った所だけが色を持つ」ものとして扱う。展開図の表示では確認用の紙の色の上に、立体では紙の種類の色の上に重ねる（それまでは、読み込んだ絵が紙ごと刷った絵として立体に貼られていた）。
- 前の版で書き出した型紙に描いた PSD は、紙の色が絵柄に入ったまま。読み戻すと、これまでどおり紙の色ごと刷る絵になる。
