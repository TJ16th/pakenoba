## 1. 前のパケノバの作り（なぜいまいちだったか）

前のパケノバ（`src/domain/materialAppearance.ts`、`BoxViewer.ts`、`docs/specification.md`）を読んだ。

| 項目 | 前の作り |
|---|---|
| 紙 | 4 種の見本（コート白、上質、クラフト、段ボール）。持つのは「色」と「粗さ」の 2 つの数だけ |
| コート | 5 種（なし、マットニス、グロスニス、マット PP、グロス PP）。粗さを少しずらし、three.js のクリアコートを足すだけ |
| 効く範囲 | 箱全体に一括。面ごと、場所ごとには変えられない |
| 箔・エンボス | 対象外（仕様書に「箔、エンボス、外部の粗さ・法線・金属光沢マップは対象外」と書いてある） |
| 照らし方 | 決まった明かり。周りの景色の映り込み（環境マップ）が弱い |

いまいちだった理由は、次の 3 つと見ている。

1. **紙に「きめ」がない。** 粗さが面全体で同じ 1 つの数なので、上質紙もクラフトも、色の違うつるつるの板に見える。本物の紙らしさは、繊維の細かい凹凸と、場所ごとの粗さのむらから来る。
2. **コートの違いが映り込みで見えない。** グロスの「テカテカ」は、周りの景色がくっきり映ることで分かる。決まった明かりが 1〜2 個だけだと、白い点が出るか出ないかの違いにしかならない。
3. **箔は金属なので、別の計算が要る。** 金属は、色が「映り込み」そのもので、拡散の色がほとんどない。紙と同じ材質の数値をいじっても箔には見えない。しかも箔は場所ごと（柄の形）なので、箱全体の設定では表せない。

## 2. Adobe 系での扱い

| 道具 | 箔・白版・特色の扱い |
|---|---|
| Illustrator | 箔用のレイヤーを分け、名前を付けた特色スウォッチ（例: 「Foil」「Gold」）で 100% のベタ塗り。オーバープリントを有効にする。ベクターで作る |
| Photoshop | 「スポットカラーチャンネル」として持つ。チャンネル名が印刷所の機械（RIP）にとって意味を持つ |
| InDesign / PDF | 特色（Separation）の版として書き出す。印刷所が版を分けて、箔の型を作る |
| エンボス | 箔と同じ形。「Emboss」などの名前の特色版を 1 枚足し、そこが型になる。高さは別の指示書で伝える |

Adobe の道具には、箔の金属光沢や浮き出しを画面で見せる仕組みはない（版として持つだけ）。見た目を確かめるには、別の 3D の道具を使うのがふつう。

→ パケノバが箱の形で箔とエンボスを見せられれば、Adobe にはない強みになる。データの持ち方は Adobe と同じ「名前の付いた版」にして、書き出しをそのまま印刷所へ渡せる形にする。

## 3. 考え方

見た目を決めるものを 3 つに分ける。

1. **紙**: 箱全体の素材。紙の種類と、きめ。
2. **コート**: 紙の上に全体に掛かるもの（ニス、PP）。
3. **加工の版（特殊版）**: 場所ごとに掛かるもの。箔、部分 UV ニス（スポット UV）、エンボス・デボス、白版、特色。

1 と 2 は案件全体の設定（前のパケノバと同じ）。3 は**専用のレイヤー**にする。

### 3.1 加工のレイヤー（特殊版）

- レイヤーの欄に、柄の並びとは別の「加工」の並びを作る（紙の表と紙の裏、それぞれに）。
- 1 枚の加工レイヤーは「どの加工か」と「形（白黒の絵）」を持つ。形は、レイヤーマスクと同じ白黒の絵（`masks/<sha>.gray` と同じ持ち方）。白が加工する場所。
- 形の作り方: 柄（文字、図形、画像）から作る、画像を読み込む、マスクと同じ道具で作る。**柄から作った場合は、その柄とつないでおき、柄を動かすと加工も付いてくる**（文字に箔を押す、がいちばん多い使い方なので）。
- 印刷の色の上に重ねる版なので、描画モードや不透明度は持たない（印刷所へは 100% で渡す）。
- 加工の種類と持つ値:

| 種類 | 持つ値 | 画面での見え方 |
|---|---|---|
| 箔押し | 箔の種類（金、銀、銅、赤金、つや消し金・銀、ホログラム、色箔）、つや（鏡面〜つや消し） | 金属として計算。周りの景色が箔の色で映る。箱を回すと光る |
| 部分 UV ニス | つや（グロス、マット）、厚み | 紙の上に、透明で光る膜。グロスなら景色がくっきり映る |
| エンボス・デボス | 高さ（mm）、向き（浮かせる・へこませる）、縁の傾き（縁の幅 mm） | 陰影の向きが変わる（3.2） |
| 白版 | なし | 透明フィルムやクラフト紙で、色の下に白を敷く。白い所だけ色が明るく出る |
| 特色 | 色の名前（DIC、PANTONE など）、見せる色 | 指定の色のベタ |

- 箔とエンボスを同じ場所に重ねる（空押し＋箔、浮き出し箔）は、2 枚のレイヤーを同じ柄につなぐだけで表せる。

### 3.2 エンボスの持ち方

ご質問の「ノーマル、デプス、ハイトマップのどれで持つか」には、**ハイトマップ（高さの白黒の絵）で持ち、ノーマルは描くときに高さから計算する**のがよいと考える。

- **ハイトマップで持つ理由**
  - 印刷所へ渡す版と同じものになる（白い所が型）。ノーマルマップは印刷では使えない。
  - 人が直しやすい。白黒の絵なので、マスクと同じ道具で描き直せる。
  - 段階のある浮き出し（彫刻型）も、灰色の濃さで表せる。白が一番高い、灰色は途中の高さ。
  - 縁の傾きを数で変えられる。持つのは「平らな形」と「縁の幅」で、坂は描くときにぼかして作る。だから型の形を変えずに、縁を急にしたり、なだらかにしたりできる。
- **ノーマルを計算で作る理由**
  - 高さを変えたら、すぐ見た目に効く（ノーマルを持つと作り直しになる）。
  - GPU で、高さの絵の隣どうしの差から求められる。軽い。
- **デプス（本当に面を凸凹にする）は使わない。** エンボスの高さは 0.2〜1 mm ほどで、箱を見る距離では、面の形が変わって見えることはない。見えるのは、光の当たり方と影の違いだけ。だから法線（陰影の向き）を変えるだけで十分に見える。輪郭の横から見たときの段差は、あとで要るとわかったら考える。
- 紙の裏側では、凸凹が逆になる（表で浮き出した所は、裏ではへこむ）。同じハイトマップを反転して使う。
- 箔と重ねたときは、箔の金属の計算にも、同じ法線を使う。縁でキラッと光るのが、浮き出し箔らしさになる。

### 3.3 紙

- 紙の見本は前と同じく持つ（コート紙、マットコート紙、上質紙、クラフト、段ボール、板紙など）。ただし、1 枚ごとに次を持たせる。
  - 色（紙の地の色）
  - 粗さ（つや）
  - **きめの絵**（繊維の凹凸のハイトマップ。小さな絵を繰り返して貼る）。紙ごとに細かさと強さが違う。
  - 粗さのむら（同じきめの絵から作る）
- きめの絵は、ノイズから計算で作り、同梱する。ライセンスの心配がない。
- 印刷した色は、紙の色と掛け合わせる（クラフトに刷ると暗く、茶色っぽくなる）。白版がある所だけは、白の上に刷った色にする。

### 3.4 コート

- 種類は前と同じ（なし、マットニス、グロスニス、マット PP、グロス PP）に、「ソフトタッチ（ベルベット）PP」を足す。
- クリアコート（紙の上の透明な膜）として計算する。グロスは膜の粗さを小さく、マットは大きく。
- 部分 UV ニスは、全体のコートの上にもう 1 枚の膜として足す（マット PP の上の部分グロス、がよくある組み合わせなので）。

### 3.5 照らし方

- 周りの景色の絵（環境マップ）で照らす。映り込みこそが、コートと箔の違いの正体なので、ここがいちばん効く。
- 景色は数種類を選べるようにする（明るい撮影ボックス、店の棚、窓のある部屋など）。ライセンスが CC0 の HDR を使う（Poly Haven の HDRI は CC0）。同梱するか、初回に取ってくるかは大きさで決める。
- 明かりの向きを、ドラッグで回せるようにする。箔の光り方を確かめるため。
- 書き出す 3D の絵（画像、GIF）にも、同じ照らし方を使う。

## 4. 描き方（いまの 3D 表示に足すもの）

いまの 3D 表示（wgpu、`gpu.rs` の 1 本のシェーダー）は、柄の色と紙の色を混ぜ、決まった明かり 1 つで陰影を付けているだけ。次を足す。

1. 紙・コート・箔を、1 つの物理的な計算（GGX の映り込み、金属・非金属、クリアコートの膜）にまとめる。three.js の `MeshPhysicalMaterial` と同じ考え方を、WGSL で書く。
2. 加工の版を、柄の絵と同じ大きさの絵として GPU へ送る。1 枚の絵の 4 つのチャンネルに、高さ、箔の量、ニスの量、白版を入れる。箔の種類が複数あるときは、チャンネルを足す。
3. 環境マップを、事前にぼかした段階（粗さごと）を持つ絵にして、映り込みを引く。
4. 色の最後の仕上げ（トーンマッピング）を入れ、白飛びを防ぐ。

## 5. 書き出し

- **PSD**: 加工のレイヤーごとに、スポットカラーチャンネルとして書き出す。名前は「Foil Gold」「Emboss」「Spot UV」「White」などにし、案件ごとに名前を変えられるようにする。craft-psd は、合成画像の追加チャンネルと、その名前（リソース 1045、1006）を読み書きできる。スポットチャンネルの色と種類を示すリソース 1077（DisplayInfo）は直接の扱いがないので、書き足すか、生のリソースとして足す。作る前に確かめる。
- **PDF**: 特色（Separation の色空間）の版として書き出す。オーバープリントを付ける。いまの PDF の書き出しに足す。
- **印刷所への指示**: 加工ごとの一覧（種類、箔の色、エンボスの高さ）を、PDF の別ページか、テキストで添える。

## 6. 作る順（案）

1. 照らし方と描き方（4 の 1、3、4）。紙とコートを、前より良く見せる。いちばん効き目が大きい。
2. 紙のきめ（3.3）。
3. 加工のレイヤーの仕組み（3.1）と、箔押し。柄から形を作る、つなぐ。
4. エンボス・デボス（3.2）。箔との重ね。

## 7. 決めたこと（2026-11-24）

- 加工のレイヤーは、レイヤーの欄の中に「加工」の並びとして置く。
- 箔の種類は、まず 金、銀、銅、赤金、つや消し金・銀、ホログラム。
- 景色は、3DCG でよく使う 360 度の環境マップ。スタジオの照明を数種類と、晴天の屋外など。屋外ははじめて使うときに取ってくる。
- エンボスの高さは mm で入れる。

## 8. 作ったもの（2026-11-24）

### 景色（`env.rs`）

- スタジオの景色 3 つは、計算で作る（取ってこない）: やわらかい光（真上と奥の上のソフトボックス、左右の後ろの細長い照明、手前の弱い光）、一灯（暗い部屋で左上から強い光と、後ろから縁の光）、白（白ホリ）。
- 屋外の 3 つは、Poly Haven（CC0）の 1K の HDR を、はじめて使うときに取ってきて、使う人のデータのフォルダの `environments/` にしまう: 晴天（kloofendal_43d_clear）、晴れ・雲あり（kloofendal_48d_partly_cloudy）、曇り（quarry_cloudy）。取ってくる先は `https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/1k/<名前>_1k.hdr`。ここ（作業の環境）からは Poly Haven へつながらないので、取ってくるところは、まだ本物で試していない。
- Radiance HDR（.hdr）を読む部品を自分で書いた（新しい形のランレングス圧縮と、圧縮なし）。
- 景色から、粗さ 6 段階にぼかした絵（横 512, 256, … 16 px）と、拡散の光（球面調和の 9 個の係数）を作る。ぼかしは GGX の山に近い cos の n 乗で、近くの画素だけを足す（スレッドで分ける）。
- 明るさは、箱の正面（見ている人の側の少し上を向いた面）の白い紙が 0.9 になるようにそろえる。いちばん明るい向きは 1.5 まで。

### 描き方（`gpu.rs`）

- 紙は、拡散（景色の拡散の光 × 色）と、紙自身のつやの映り込み（粗さに合わせてぼかした景色）。コートは、その上の透明な膜の映り込み。映り込みの強さは、反射率 0.04 の近似式（Karis）。
- 景色は、視点の左右の向きといっしょに回る。箱を回して見ると、照明に対して箱が回るので、つやの光り方が変わる（手で箱を回すのと同じ）。
- 箱の内側の面は、外より暗くする（0.7 倍）。
- 最後に、明るすぎる所だけを丸める（Khronos PBR Neutral）。0.76 までの色は変えないので、柄の色はそのまま出る。
- 画像と動画の書き出しも、同じ描き方。

### 紙とコート

- 案件に持たせる（`project.toml` の `[material]`。はじめの「コートボール、コートなし」のときは書かない）。
- 紙: コートボール（裏グレー）、コート紙、マットコート紙、上質紙、クラフト紙、段ボール。表、裏、切り口の色と粗さを持つ。
- コート: なし、マットニス、グロスニス、マット PP、グロス PP、ソフトタッチ PP。強さ、粗さ、色の深まり（グロスで少し濃く、マットで少し白っぽく）を持つ。
- 型の工程の右の欄の「紙とコート」で選ぶ。エージェントからは `material.set`。

### 照明の選び方

- 立体の表示の右上の「照明」: 景色を選ぶ、回す（-180〜180 度）、明るさ（-2〜+2 段）。案件ではなく、アプリの設定に覚える。

### 紙のきめ（2026-11-24）

- 紙の表面の凹凸を、シェーダーの中で雑音から作る（絵のファイルは持たない）。紙ごとに、繊維の大きさ（mm）、表と裏の凹凸の高さ（mm）、色のむらを持つ。段ボールは、4 mm おきの段のうねりも足す。
- 凹凸は、面の向き（法線）だけをずらす。コートの膜は平らなので、膜の映り込みはずらさない（グロス PP の下に紙のきめが透けて見える形）。
- 1 画素が繊維より大きく見えるほど離れると、ちらつかないように細かいきめを薄くする。数 mm の雲のような色のむら（クラフト紙で目立つ）は、遠くからも見える。
- 立体に貼る絵は、刷った所だけが色を持つようにした（それまでは、展開図の表示と同じく、紙の色で塗りつぶした絵を貼っていたので、紙の種類を変えても白いままだった）。紙の色、つや、きめは、描くときに紙の種類から付ける。刷った色は紙の色と掛け合わせる（クラフト紙では暗く、茶色っぽくなる）。展開図の表示は、これまでどおり確認用の紙の色の上に描く。読み込んだ展開図の絵（PSD）があるときは、紙ごと刷った絵なので、そのまま貼る。

### 加工のレイヤーと箔押し（2026-11-24）

- 加工のレイヤーは、柄のレイヤーとは別に持つ（`Project::finishes`。`project.toml` の `[[finish]]` に、印、種類 `foil`、箔の種類、つないだ柄の印、名前、隠しているか）。
- 形は、つないだ柄の形をそのまま借りる（柄を動かす、大きさを変える、回すと、箔も付いてくる）。柄を隠しても形には使うので、「インキを刷らずに箔だけを押す」は、柄のレイヤーを隠すだけで表せる。柄のマスクも効く。不透明度と描画モードは効かない（箔は 100% で押す）。
- つないだ柄を消すと、加工は残り、「つないでいた柄がありません」と出る（元に戻せば、つながり直す）。
- 作り方: 柄を選んで、レイヤーの欄のいちばん下の星のボタンから、箔の種類を選ぶ。エージェントと MCP からは `finish.add`、`finish.set`、`finish.delete`。`doc.inspect` に `finishes` を出す。
- レイヤーの欄では、紙の面ごとに、柄の上に並べる（刷ったあとに押すので、いちばん上）。行は、目、箔の色の四角と星の印、名前（はじめは「金箔（ロゴ）」）、その下に「箔押し」。押すと選び、プロパティに、箔の種類、形の元の柄（押すとその柄を選ぶ）、「箔を外す」。右クリックでも外せる。
- 描くとき: 表と裏それぞれに、加工の版の絵（展開図の大きさ。R が箔の量、G が箔の種類）を作って GPU へ送る。箔は、景色を箔の色で映す金属として計算する（拡散の色はほとんどない）。押した箔の小さなうねりと紙のきめを少し拾うので、映る景色がずれて、明るい所と暗い所ができる。ホログラムは、銀を土台に、見る向きで虹の色が流れる。コートの上に押す（箔がいちばん上）。
- 展開図の表示では、箔の場所を、その箔の色（金、銀など）で塗って見せる。
- 押した箔の小さなうねりは、加工ごとに「うねり」（0〜100%、はじめは 20%）で変えられる（本人の要望、2026-11-24）。0 は鏡のように平ら。加工の版の絵の B に入れて送る。つまみを引いている間は見た目だけを変え、離したときに 1 回の操作として記録する。案件の `[[finish]]` の `wave`（はじめの値のときは書かない）。
- やわらかいスタジオの景色に、床の白い台（水平より 12〜45 度下の明るい帯）を足した。箔やグロスの正面に、明るい帯として映る。
- シェーダーの書き間違いは、起動して初めて分かる（GPU の部品が読むとき）。naga（wgpu と同じ版、MIT か Apache-2.0）で読んで型を確かめる試験を足した（`gpu.rs` の試験。部品は試験のときだけ使う）。

### エンボス・デボス（2026-11-24）

- 加工のレイヤーの種類 `emboss`。持つのは、高さ（mm。0.05〜2、はじめは 0.4）、へこませるか（デボス）、縁の坂の幅（mm。0.1〜3、はじめは 0.6）。形は箔と同じく、つないだ柄の形を借りる。柄を隠せば空押し。同じ柄に箔もつなげば、浮き出し箔。
- 高さは、3.2 の考えどおりハイトマップで持ち、描くときに坂から面の向きを求める。加工の版の絵の A に、高さを入れる（128 が 0、255 が 2 mm、0 が −2 mm）。柄の形を、縁の幅だけぼかして（箱ぼかし 2 回）坂にし、高さを掛けて足し合わせる。
- シェーダーでは、版の隣の画素との差から坂（mm あたり）を出し、面の向きを傾ける。紙、コート、箔は、どれもこの向きに従う（浮き出し箔の縁がキラッと光る）。紙の表から押した浮き出しは、裏（箱の内側）から見るとへこみ。表と裏の版の差で求める。
- 展開図の表示では、浮き出しを少し明るく、へこみを少し暗く見せる。
- 作り方は、レイヤーの欄の星のボタンの「エンボス（浮かせる）」「デボス（へこませる）」。プロパティで、向き、高さ、縁の幅。エージェントからは `finish.add`（`kind = "emboss"`、`height`、`edge`、`deboss`）と `finish.set`。案件の `[[finish]]` には `kind = "emboss"`、`height`、`deboss`、`edge`（はじめの値のときは書かない）。

### 付属の見本（2026-11-24、本人の要望）

- ホーム画面の「見本を開く」から、4 つの見本の案件を開ける。開くと名前のない新しい案件になり、見本そのものは変わらない。
  - 箔押しの見本: 紺のベタにマット PP、7 種の箔を並べ、フタに金箔のロゴ。
  - エンボスの見本: 上質紙に、高さ違いの空押し（0.2、0.5、1.0 mm）、デボス、浮き出しの金箔、刷った色の上のエンボス、フタのロゴのエンボス。
  - クラフト紙: 箱を一周するホログラムの帯、フタに銅箔＋エンボス、側面にデボス、ロゴの上に軽いエンボス。
  - 黒にグロス PP: 金の浮き出し箔のロゴと、つや消し銀の枠。
- 見本は、絵の素材を使わない案件（図形と付属の見本の柄だけ）なので、設定のテキスト（`assets/samples/*.toml`）だけを同梱し、`Project::from_text` で読む。どの見本も傷なく開け、加工がつなぐ柄がそろっていることを試験で確かめる。

### 部分 UV ニスと白版（2026-11-24）

- 加工のレイヤーの種類 `spot_uv`（`matte` でつや消し）と `white`。形は、ほかの加工と同じく、つないだ柄の形を借りる。
- 部分 UV ニスは、全体のコートの上のもう 1 枚の膜として描く（グロスは粗さ 0.035、マットは 0.5）。グロスでは色も少し深くなる。マット PP の上にグロスで引くと、その形だけが光る。
- 白版は、刷った色の下に白いインキを敷く。白版のある所は、紙の色のかわりに白インキの上に刷った色になる（クラフト紙で、色が鮮やかに出る）。刷っていない所に白版だけがあれば、白く見える。
- 加工の版の絵を 2 枚 1 組にした。2 枚目は、R が部分 UV ニスの量、G がそのつや消しの度合い、B が白版の量。
- 展開図の表示では、部分 UV ニスを薄い水色、白版を白で重ねて見せる。
- 見本: クラフト紙の見本のロゴに白版を足した。黒の見本は、マット PP にして、ロゴのまわりの円に部分 UV ニス（グロス）を足した。

### 特色について（2026-11-24、本人との話）

- 特色は、CMYK の掛け合わせでは出ない色（鮮やかなオレンジや緑、蛍光、金や銀のインキ）や、ブランドの色を毎回同じに出すために、調合したインキで刷るもの。作業が RGB でも、ふつうの印刷は CMYK に直して刷るので、色域の外の色はくすむ。
- パケノバはいま色を RGB でしか扱っていないので、特色は、CMYK に直したときの見え方の確認（どの色がくすむか）と一緒に作る。
