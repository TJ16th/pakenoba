# 新パケノバ 紙・コート・加工の検討

- 作成日: 2026-11-24
- 状態: 検討中（まだ作っていない）
- 関連: [レイヤーの検討](layers.md)、[案件の保存の検討](project-file.md)

本人からの要望（2026-11-24）。

- 前のパケノバにも紙の質やコートの設定はあったが、紙の感じ、コートのテカテカ感、箔押しのキラキラ感がうまく出ていなかった。作り直しでは、そこを良くして入れたい。
- 箔押しは専用のレイヤーとして持たせる。
- エンボスはテクスチャー（ノーマル、デプス、ハイトマップ）で持たせるのがよいか。

## 1. 前のパケノバの作り（なぜいまいちだったか）

前のパケノバ（`src/domain/materialAppearance.ts`、`BoxViewer.ts`、`docs/specification.md`）を読んだ。

| 項目 | 前の作り |
|---|---|
| 紙 | 4 種の見本（コート白、上質、クラフト、段ボール）。持つのは「色」と「粗さ」の 2 つの数だけ |
| コート | 5 種（なし、マットニス、グロスニス、マット PP、グロス PP）。粗さを少しずらし、three.js のクリアコートを足すだけ |
| 効く範囲 | 箱全体に一括。面ごと、場所ごとには変えられない |
| 箔・エンボス | 対象外（仕様書に「箔、エンボス、外部の粗さ・法線・金属光沢マップは対象外」と書いてある） |
| 照らし方 | 決まった明かり。周りの景色の映り込み（環境マップ）が弱い |

いまいちだった理由は、次の 3 つと見ている。

1. **紙に「きめ」がない。** 粗さが面全体で同じ 1 つの数なので、上質紙もクラフトも、色の違うつるつるの板に見える。本物の紙らしさは、繊維の細かい凹凸と、場所ごとの粗さのむらから来る。
2. **コートの違いが映り込みで見えない。** グロスの「テカテカ」は、周りの景色がくっきり映ることで分かる。決まった明かりが 1〜2 個だけだと、白い点が出るか出ないかの違いにしかならない。
3. **箔は金属なので、別の計算が要る。** 金属は、色が「映り込み」そのもので、拡散の色がほとんどない。紙と同じ材質の数値をいじっても箔には見えない。しかも箔は場所ごと（柄の形）なので、箱全体の設定では表せない。

## 2. Adobe 系での扱い

| 道具 | 箔・白版・特色の扱い |
|---|---|
| Illustrator | 箔用のレイヤーを分け、名前を付けた特色スウォッチ（例: 「Foil」「Gold」）で 100% のベタ塗り。オーバープリントを有効にする。ベクターで作る |
| Photoshop | 「スポットカラーチャンネル」として持つ。チャンネル名が印刷所の機械（RIP）にとって意味を持つ |
| InDesign / PDF | 特色（Separation）の版として書き出す。印刷所が版を分けて、箔の型を作る |
| エンボス | 箔と同じ形。「Emboss」などの名前の特色版を 1 枚足し、そこが型になる。高さは別の指示書で伝える |

Adobe の道具には、箔の金属光沢や浮き出しを画面で見せる仕組みはない（版として持つだけ）。見た目を確かめるには、別の 3D の道具を使うのがふつう。

→ パケノバが箱の形で箔とエンボスを見せられれば、Adobe にはない強みになる。データの持ち方は Adobe と同じ「名前の付いた版」にして、書き出しをそのまま印刷所へ渡せる形にする。

## 3. 考え方

見た目を決めるものを 3 つに分ける。

1. **紙**: 箱全体の素材。紙の種類と、きめ。
2. **コート**: 紙の上に全体に掛かるもの（ニス、PP）。
3. **加工の版（特殊版）**: 場所ごとに掛かるもの。箔、部分 UV ニス（スポット UV）、エンボス・デボス、白版、特色。

1 と 2 は案件全体の設定（前のパケノバと同じ）。3 は**専用のレイヤー**にする。

### 3.1 加工のレイヤー（特殊版）

- レイヤーの欄に、柄の並びとは別の「加工」の並びを作る（紙の表と紙の裏、それぞれに）。
- 1 枚の加工レイヤーは「どの加工か」と「形（白黒の絵）」を持つ。形は、レイヤーマスクと同じ白黒の絵（`masks/<sha>.gray` と同じ持ち方）。白が加工する場所。
- 形の作り方: 柄（文字、図形、画像）から作る、画像を読み込む、マスクと同じ道具で作る。**柄から作った場合は、その柄とつないでおき、柄を動かすと加工も付いてくる**（文字に箔を押す、がいちばん多い使い方なので）。
- 印刷の色の上に重ねる版なので、描画モードや不透明度は持たない（印刷所へは 100% で渡す）。
- 加工の種類と持つ値:

| 種類 | 持つ値 | 画面での見え方 |
|---|---|---|
| 箔押し | 箔の種類（金、銀、銅、赤金、つや消し金・銀、ホログラム、色箔）、つや（鏡面〜つや消し） | 金属として計算。周りの景色が箔の色で映る。箱を回すと光る |
| 部分 UV ニス | つや（グロス、マット）、厚み | 紙の上に、透明で光る膜。グロスなら景色がくっきり映る |
| エンボス・デボス | 高さ（mm）、向き（浮かせる・へこませる）、縁の傾き（縁の幅 mm） | 陰影の向きが変わる（3.2） |
| 白版 | なし | 透明フィルムやクラフト紙で、色の下に白を敷く。白い所だけ色が明るく出る |
| 特色 | 色の名前（DIC、PANTONE など）、見せる色 | 指定の色のベタ |

- 箔とエンボスを同じ場所に重ねる（空押し＋箔、浮き出し箔）は、2 枚のレイヤーを同じ柄につなぐだけで表せる。

### 3.2 エンボスの持ち方

ご質問の「ノーマル、デプス、ハイトマップのどれで持つか」には、**ハイトマップ（高さの白黒の絵）で持ち、ノーマルは描くときに高さから計算する**のがよいと考える。

- **ハイトマップで持つ理由**
  - 印刷所へ渡す版と同じものになる（白い所が型）。ノーマルマップは印刷では使えない。
  - 人が直しやすい。白黒の絵なので、マスクと同じ道具で描き直せる。
  - 段階のある浮き出し（彫刻型）も、灰色の濃さで表せる。白が一番高い、灰色は途中の高さ。
  - 縁の傾きを数で変えられる。持つのは「平らな形」と「縁の幅」で、坂は描くときにぼかして作る。だから型の形を変えずに、縁を急にしたり、なだらかにしたりできる。
- **ノーマルを計算で作る理由**
  - 高さを変えたら、すぐ見た目に効く（ノーマルを持つと作り直しになる）。
  - GPU で、高さの絵の隣どうしの差から求められる。軽い。
- **デプス（本当に面を凸凹にする）は使わない。** エンボスの高さは 0.2〜1 mm ほどで、箱を見る距離では、面の形が変わって見えることはない。見えるのは、光の当たり方と影の違いだけ。だから法線（陰影の向き）を変えるだけで十分に見える。輪郭の横から見たときの段差は、あとで要るとわかったら考える。
- 紙の裏側では、凸凹が逆になる（表で浮き出した所は、裏ではへこむ）。同じハイトマップを反転して使う。
- 箔と重ねたときは、箔の金属の計算にも、同じ法線を使う。縁でキラッと光るのが、浮き出し箔らしさになる。

### 3.3 紙

- 紙の見本は前と同じく持つ（コート紙、マットコート紙、上質紙、クラフト、段ボール、板紙など）。ただし、1 枚ごとに次を持たせる。
  - 色（紙の地の色）
  - 粗さ（つや）
  - **きめの絵**（繊維の凹凸のハイトマップ。小さな絵を繰り返して貼る）。紙ごとに細かさと強さが違う。
  - 粗さのむら（同じきめの絵から作る）
- きめの絵は、ノイズから計算で作り、同梱する。ライセンスの心配がない。
- 印刷した色は、紙の色と掛け合わせる（クラフトに刷ると暗く、茶色っぽくなる）。白版がある所だけは、白の上に刷った色にする。

### 3.4 コート

- 種類は前と同じ（なし、マットニス、グロスニス、マット PP、グロス PP）に、「ソフトタッチ（ベルベット）PP」を足す。
- クリアコート（紙の上の透明な膜）として計算する。グロスは膜の粗さを小さく、マットは大きく。
- 部分 UV ニスは、全体のコートの上にもう 1 枚の膜として足す（マット PP の上の部分グロス、がよくある組み合わせなので）。

### 3.5 照らし方

- 周りの景色の絵（環境マップ）で照らす。映り込みこそが、コートと箔の違いの正体なので、ここがいちばん効く。
- 景色は数種類を選べるようにする（明るい撮影ボックス、店の棚、窓のある部屋など）。ライセンスが CC0 の HDR を使う（Poly Haven の HDRI は CC0）。同梱するか、初回に取ってくるかは大きさで決める。
- 明かりの向きを、ドラッグで回せるようにする。箔の光り方を確かめるため。
- 書き出す 3D の絵（画像、GIF）にも、同じ照らし方を使う。

## 4. 描き方（いまの 3D 表示に足すもの）

いまの 3D 表示（wgpu、`gpu.rs` の 1 本のシェーダー）は、柄の色と紙の色を混ぜ、決まった明かり 1 つで陰影を付けているだけ。次を足す。

1. 紙・コート・箔を、1 つの物理的な計算（GGX の映り込み、金属・非金属、クリアコートの膜）にまとめる。three.js の `MeshPhysicalMaterial` と同じ考え方を、WGSL で書く。
2. 加工の版を、柄の絵と同じ大きさの絵として GPU へ送る。1 枚の絵の 4 つのチャンネルに、高さ、箔の量、ニスの量、白版を入れる。箔の種類が複数あるときは、チャンネルを足す。
3. 環境マップを、事前にぼかした段階（粗さごと）を持つ絵にして、映り込みを引く。
4. 色の最後の仕上げ（トーンマッピング）を入れ、白飛びを防ぐ。

## 5. 書き出し

- **PSD**: 加工のレイヤーごとに、スポットカラーチャンネルとして書き出す。名前は「Foil Gold」「Emboss」「Spot UV」「White」などにし、案件ごとに名前を変えられるようにする。craft-psd は、合成画像の追加チャンネルと、その名前（リソース 1045、1006）を読み書きできる。スポットチャンネルの色と種類を示すリソース 1077（DisplayInfo）は直接の扱いがないので、書き足すか、生のリソースとして足す。作る前に確かめる。
- **PDF**: 特色（Separation の色空間）の版として書き出す。オーバープリントを付ける。いまの PDF の書き出しに足す。
- **印刷所への指示**: 加工ごとの一覧（種類、箔の色、エンボスの高さ）を、PDF の別ページか、テキストで添える。

## 6. 作る順（案）

1. 照らし方と描き方（4 の 1、3、4）。紙とコートを、前より良く見せる。いちばん効き目が大きい。
2. 紙のきめ（3.3）。
3. 加工のレイヤーの仕組み（3.1）と、箔押し。柄から形を作る、つなぐ。
4. エンボス・デボス（3.2）。箔との重ね。
5. 部分 UV ニス、白版、特色。
6. PSD と PDF の書き出し（5）。

## 7. 決めてほしいこと

- 加工のレイヤーの置き場所: レイヤーの欄の中に「加工」の並びを作る（案）か、別の欄にするか。
- 箔の種類の最初の一式: 金、銀、銅、赤金、つや消し金・銀、ホログラム、で足りるか。
- 景色（環境マップ）: 同梱する数と、初回に取ってくるかどうか。
- エンボスの高さを mm で入れるか、「弱・中・強」で選ぶか（中では mm を持つ）。
