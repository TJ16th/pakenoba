# PAKENOBA

パッケージデザイン専用の制作ソフトです。

## 使い方

1. `pakenoba-<版>-windows-x64-portable.zip` を取ってきて、好きな場所に解凍します。
2. `pakenoba.exe` を開きます（インストールは要りません）。
3. 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」で開けます（まだコード署名をしていないため）。

`SHA256SUMS.txt` は、ダウンロードしたファイルが壊れていないかを確かめる値です（アプリ内のアップデートも使います）。

## この版の変わったところ

最初の公開版です。基本的な機能を盛り込んでみました。パッケージデザインの仕事をされている方、個人でちょっとしたパッケージを作りたい方の手助けになると幸いです。

主な機能:

- 箱の型: 差し込み箱、ゲーブル型、ピロー型（持ち手あり・なし）、角柱、ECMA の型、DXF の読み込み
- 立体の上で、画像・文字・図形を置いて、そのまま展開図に反映
- レイヤー、調整レイヤー、マスク、タイル、ベクター化
- 書き出し: 展開図の PDF、入稿用 PDF（CMYK）、PSD
- MCP で、AI のエージェントから操作
