# PAKENOBA

パッケージデザイン専用の制作ソフトです。

## 使い方

1. `pakenoba-<版>-windows-x64-portable.zip` を取ってきて、好きな場所に解凍します。
2. `pakenoba.exe` を開きます（インストールは要りません）。
3. 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」で開けます（まだコード署名をしていないため）。

`SHA256SUMS.txt` は、ダウンロードしたファイルが壊れていないかを確かめる値です（アプリ内のアップデートも使います）。

## この版の変わったところ

- ECMA の型を、組んだ形と展開図の絵を見比べて選べるようにしました（型の欄の「絵を見て選ぶ…」）。
- ECMA の型で、フタの下に入るフラップやのりしろが、立体の表に突き抜けて見えていたのを直しました。
- ピロー型などで、折り目やのりしろのところに白い筋が出ていたのを直しました。
- ベクター化した柄の「ベクターの見せ方」を「塗りと線」という呼び方にしました。
- 実行ファイルにアイコンを付けました。
