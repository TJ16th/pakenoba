# 利用状況の送信

- 作成日: 2026-11-25
- 状態: 作った（`crates/pakenoba-app/src/app/usage.rs`）
- 送り先: [Aptabase](https://aptabase.com/)（匿名のアプリ分析。無料の枠は月 2 万イベント。超えると、その月は記録が止まるだけで、課金はされない）

## 決めたこと

- 同意した人からだけ送る。はじめて起動したときに聞き、はじめの答えは「送らない」と同じ扱い（どちらかを押すまで送らない）。
- 「編集」→「環境設定」→「利用状況」で、いつでも切れる。送ったものは「送る内容を見る」で、送ったそのままの形で見られる。
- 送るのは、決めた少しのイベントだけ。案件の中身、ファイルの名前、絵、文字は送らない。アカウントや端末を見分ける番号も使わない。
- 自分についての答え（仕事と年代）は、別の印で同意したときだけ、起動のイベントに付ける。どちらも「答えない」を選べ、「答えを消す」で消せる。性別は、使い道がはっきりしないので聞かない。
- 送り先の鍵（App Key）は、公式の配布物をビルドするときだけ、環境変数 `PAKENOBA_APTABASE_KEY` で入れる。鍵なしでビルドしたもの（自分でビルドしたもの、改造して配るもの）は、何も送らず、同意も聞かない。

## 送るイベント

| 名前 | いつ | 中身（props） |
|---|---|---|
| `app_started` | 起動したとき（同意を聞いたときは、答えたあと） | 同意したときだけ `job`、`age` |
| `shape_chosen` | 箱の型を変えたとき（起動したときの型は送らない。同じ型は続けて送らない） | `shape`（`tuck_box`、`gable`、`pillow`、`plain_pillow`、`prism3` など、ECMA は `ecma:A20.20.03.01`、DXF は `dxf` だけで、ファイルの名前は送らない） |
| `export` | 書き出す場所を選んだとき | `format`（`png`、`gif`、`pdf`、`glb`、`obj`、`psd`）。PSD は `output`（`dieline`、`atlas`） |
| `print_ready_color` | 入稿用の PDF を書き出すとき | `color`（`rgb`、`cmyk_builtin`、`cmyk_icc`） |
| `ai_used` | AI の機能を使ったとき | `feature`（`agent` と `provider`、`local_ai_tags` と `count`、`image_trace`、`mcp_window`） |

Aptabase の決まりで、どのイベントにも `systemProps`（言語、OS の名前、デバッグ版か、アプリの版）と、起動ごとの番号（秒の時刻と乱数。人を見分けるものではない）と、時刻が付く。受け取る側が、国と地域を IP アドレスから判定する（IP 自体は残さない）。

## 作り

- 送るのは別のスレッド。2 秒待って、来たものを 25 個までまとめ、`POST https://{eu|us}.aptabase.com/api/v0/events` に送る（見出し `App-Key`）。失敗したら、その回のぶんは捨てる（アプリの動きには関わらない）。
- MCP の画面なしの動き（`pakenoba mcp`）では送らない（同意を聞く画面がないため）。
