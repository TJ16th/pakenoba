# 新パケノバ レイヤーの検討

- 作成日: 2026-11-24
- 状態: 案。作る順（4 章）の 1 から進める
- 関連: [画面設計の検討](ui-design.md)、[案件の保存の検討](project-file.md)

本人からの要望（2026-11-23〜24）は 3 つ。

- 画像の調整を、重ねられる「調整レイヤー」にする。元に戻せるようにし、Photoshop の「被写体を選択」に当たる機能も入れる。
- 調整は、柄ごとに効くものと、下のレイヤーすべてに効くものの両方を作る。
- レイヤーは Photoshop と同じにする（描画モード、不透明度、グループ、マスク）。

## 1. いまの作り

- レイヤーは「紙の表」と「紙の裏」の 2 つの並び。どちらも、柄（画像、文字、図形、付属の見本）を下から順に、展開図の大きさの 1 枚の絵へ直接描き込む。
- レイヤーごとに持っているのは、名前、表示、ロックだけ。不透明度、描画モード、マスク、グループはない。
- 画像の調整（背景を透明にする、陰影をならす、色数を絞る）は、そのたびに新しい素材を作って差し替える。重ねたり、あとから数値を直したりはできない。

## 2. Photoshop に合わせるもの

| 項目 | Photoshop | パケノバでの形 |
|---|---|---|
| 不透明度 | 0〜100%。レイヤーとグループに | 同じ。数値とスライダー。数字キー（1 で 10%、0 で 100%）は、表示の切り替えと重なるので使わない |
| 描画モード | 通常、乗算、スクリーン、オーバーレイ、ソフトライト、ハードライト、覆い焼きカラー、焼き込みカラー、比較（暗）、比較（明）、差の絶対値、除外、色相、彩度、カラー、輝度 など | この 16 種。グループは、はじめが「通過」 |
| レイヤーマスク | 白黒の絵。白は見せる、黒は隠す。レイヤーと一緒に動く（鎖のアイコン） | 柄と一緒に動くマスク。作り方は「すべて表示」「被写体から」「透明な部分から」、反転、外す。筆で描くのは、あとの段階 |
| グループ | フォルダ。開け閉め、まとめて動かす、隠す。グループにも不透明度、描画モード、マスク | 同じ。表と裏の並びの中に作る。グループをまたいで、表と裏は混ぜない |
| 調整レイヤー | 下のレイヤーすべてに効く。クリップすると、すぐ下の 1 枚だけに効く | 両方作る。柄の下にクリップした調整（その柄だけ）と、並びの中の調整レイヤー（下すべて。グループの中なら、グループの中だけ） |
| スマートフィルター | レイヤーの下に並ぶ、あとから直せる効果 | 「柄だけに効く調整」は、これと同じ見せ方にする（レイヤーの欄で、柄の下に字下げして並ぶ。目のアイコンで切り替え） |
| 被写体を選択 | AI で主な被写体を囲む | 「被写体を抽出」。マスクか、柄の調整として使う。U²-Net（Apache-2.0）。軽いモデル（u2netp、4.7 MB）を同梱し、「高画質」を選んだときだけ大きいモデル（u2net、約 170 MB）を初回に取ってくる。どちらも端末の中で動き、絵を外へ送らない |

調整の種類（はじめ）: 明るさ・コントラスト、色相・彩度、レベル補正、背景を透明にする、陰影をならす、色数を絞る、被写体を抽出。余白を切り落とすは、柄の大きさと場所が変わるので、いまのまま 1 回きりの操作にする。

## 3. 作りの考え

- 描き方を変える。柄ごとに透明な絵へ描いてから、描画モード、不透明度、マスクを使って、下の絵へ重ねる。グループは、中身を 1 枚に重ねてから、グループの設定で重ねる（「通過」のときは、中身をそのまま外へ重ねる）。調整レイヤーは、その時点までに重なった絵に効かせる。
- 速さ: 展開図の絵は、大きな型で 3000 × 2000 px ほどになる。重ねる計算は、柄がかかっている四角の中だけで行う。柄ごとの調整の結果は、元の絵と設定から作った印で覚えておき、変わったときだけ別のスレッドで作り直す（その間は前の絵を出す）。
- 元に戻す: レイヤーの設定と調整は、いまの「元に戻すための記録」に入る。スライダーのひと続きは 1 回ぶんにまとめる（いまの数値の欄と同じ）。
- 保存: `[[decal]]` に `opacity`、`blend`、`mask`、`[[decal.adjust]]` を、グループは `[[group]]`、下に効く調整レイヤーは `[[adjustment]]` として足す。どれも既定の値なら書かない。知らない描画モードや調整は、外して知らせる。足すだけなので、形式の版は 1 のまま。
- 型紙の PSD: 描画モード、不透明度、表示は、PSD のレイヤーの設定として入れる。グループは PSD のグループにする。マスクは PSD のレイヤーマスクにする。調整は、効かせた絵をレイヤーに入れる（PSD の調整レイヤーは、種類ごとに書き方が違い、Photoshop 以外で読めないことが多いため）。書き出しの部品（craft-psd）で、どこまで書けるかを作る前に確かめる。

## 4. 作る順

1. 不透明度と描画モード（描き方の作り直しを含む）。
2. 柄だけに効く調整（重ねる、切り替える、並べ替える、あとから直す）と、被写体を抽出（軽いモデル）。
3. レイヤーマスク（すべて表示、被写体から、透明な部分から、反転）。
4. グループ。
5. 下のレイヤーすべてに効く調整レイヤー。
6. 大きいモデルを、初回に取ってくる。
7. マスクを筆で描く。

## 5. 決めてほしいこと

- 作る順は、4 章のとおりでよいか。
- 数字キーで不透明度を変える Photoshop の操作は、表示の切り替え（1、2、3）と重なるので入れない。これでよいか。
