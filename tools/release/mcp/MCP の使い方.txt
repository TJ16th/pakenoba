MCP の使い方（AI のアプリから、パケノバを動かす）
==============================================

パケノバは MCP サーバーとしても動きます。VS Code（Copilot のエージェント）や Claude Desktop などの
AI のアプリから、案件を開き、柄を置き、型を変え、保存できます。

動き方は 2 つあります。
- 開いている画面を動かす: パケノバの「編集」→「環境設定」→「MCP からこの画面を動かす」を入れておくと、
  AI の変更が、開いている画面にその場で出ます。人が操作したときと同じく、元に戻せます。
  下の帯に「MCP 接続中」と出ます。
- 画面なし: 上を入れていないとき（パケノバを開いていないときも）は、画面を出さずに動きます。
  AI が作った案件は、保存したファイルをパケノバで開いて確かめます。

■ 入っているもの
- vscode-mcp.json            VS Code 用の見本
- claude_desktop_config.json  Claude Desktop 用の見本

■ VS Code
1. 作業フォルダの中に .vscode フォルダを作り、vscode-mcp.json を「mcp.json」という名前で写します。
2. 中の 2 つの場所を、自分の PC に合わせて書き換えます。
   - "command": pakenoba.exe を解凍した場所（例: C:\Tools\pakenoba\pakenoba.exe）
   - "--allow" の次: AI に読み書きさせてよいフォルダ（いくつでも並べられます）
   JSON の中では、\ を 2 つ重ねて \\ と書きます。
3. VS Code のチャットをエージェントにすると、道具の一覧に「pakenoba」が出ます。

■ Claude Desktop
Claude Desktop の「設定」→「開発者」→「設定を編集」で開くファイルに、
claude_desktop_config.json の "mcpServers" の中身を足し、同じように 2 か所を書き換えます。
書き換えたら、Claude Desktop を一度終わらせて、開き直します。

■ いつも画面なし、いつも画面へ
"args" に "--headless" を足すと、画面が開いていても、いつも画面なしで動きます。
"--window" を足すと、動かせる画面がないときは、つながずにエラーで終わります。

■ 案件を開いた状態で始める（画面なし）
"args" の最後に、案件のファイル（.pknb）の場所を足します。このときは、画面なしで動きます。
  "args": ["mcp", "--allow", "C:\\...\\pakenoba", "C:\\...\\箱.pknb"]

■ 安全のために
- AI が読み書きできるのは、--allow で渡したフォルダの中だけです。
- すでにあるファイルには上書きしません（保存は、いつも新しい名前で）。
- AI のアプリとは、標準入出力でやりとりします。
- 画面を動かすときだけ、この PC の中だけの口（127.0.0.1）を開きます。番号と合言葉は、
  自分のデータのフォルダ（%LOCALAPPDATA%\pakenoba\mcp-window.json）に書き、画面を閉じるか設定を切ると消えます。

■ AI に頼める例
- 「差し込み箱を幅 120、奥行き 40、高さ 150 にして、正面にロゴを置いて、箱.pknb で保存して」
- 「ECMA の A20.20.03.01 で、100 × 60 × 150 mm の箱にして」
- 「いまの展開図を見せて」
